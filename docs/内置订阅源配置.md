# 内置订阅源配置指南

## 📁 文件位置

**数据文件**: `src/featured-feeds.json`

> 只需编辑这个JSON文件即可修改内置订阅源列表。

## 📝 如何添加新的订阅源

### 编辑 JSON 文件

打开 `src/featured-feeds.json`，在对应的分类中添加新条目：

```json
{
  "feeds": [
    {
      "category": "Chinese Tech & Design",
      "categoryZh": "中文科技/设计",
      "items": [
        { "name": "少数派", "url": "https://sspai.com/feed" },
        { "name": "新网站", "url": "https://example.com/feed" }
      ]
    }
  ]
}
```

### JSON 结构说明

```json
{
  "feeds": [                    // 分类列表
    {
      "category": "英文分类名",   // 用于代码识别
      "categoryZh": "中文分类名", // 用于显示
      "items": [                 // 该分类下的订阅源
        { 
          "name": "网站名称", 
          "url": "RSS地址" 
        }
      ]
    }
  ]
}
```

## 🎯 最佳实践

1. **分组管理** - 使用 `category` 和 `categoryZh` 字段组织订阅源
2. **测试链接** - 添加前确保RSS链接有效且可访问
3. **命名规范** - 使用简洁清晰的中文或英文名称
4. **避免重复** - 检查是否已存在相同的订阅源
5. **JSON格式** - 确保JSON语法正确（可使用在线验证工具）
6. **保持顺序** - 按相关性或热度排序，方便用户选择

## 🔄 修改后需要做什么

1. 保存 `featured-feeds.json` 文件
2. 运行构建命令：`pnpm run build`
3. 重新加载思源笔记插件

## 💡 技术说明

**为什么只用JSON？**
- ✅ **简单** - 无需TypeScript知识，任何人都能编辑
- ✅ **清晰** - 纯数据格式，一目了然
- ✅ **灵活** - 支持分类、扩展字段等
- ✅ **安全** - TypeScript编译时检查JSON格式

**实现原理**：
- `index.ts` 直接导入 `featured-feeds.json`
- TypeScript 编译器自动进行类型检查
- 运行时自动展平为数组供UI使用
