## 一、实施内容

### 1. ✅ 已读/未读状态管理

**实现方式**：
- 新增 `ReadStatus` 数据结构存储已读状态
- 文章列表中已读文章显示灰色、不显示蓝色小点
- 点击文章自动标记为已读（可配置关闭）
- 新增"全部标记已读"按钮

**关键代码**：
```typescript
interface ReadStatus {
    [articleId: string]: {
        isRead: boolean;
        readAt?: number;
    };
}
```

---

### 2. ✅ 文章分页加载

**实现方式**：
- 默认每页显示 20 篇文章（可配置）
- 文章列表底部显示"加载更多"按钮
- 显示剩余未加载文章数量
- 滚动加载优化，避免一次性加载过多数据

**用户体验**：
```
[文章列表]
├── 文章 1-20
├── [加载更多] (还有 35 篇文章)
└── 文章 21-40 (加载后)
```

---

### 3. ✅ 历史文章缓存

**实现方式**：
- 新增 `CachedArticles` 数据结构存储历史文章
- 每次获取RSS时与缓存合并，去重
- 最多缓存每订阅源 100 篇文章
- 缓存数据持久化到思源插件存储

**关键代码**：
```typescript
interface CachedArticles {
    [subscriptionId: string]: Article[];
}

const MAX_CACHED_ARTICLES = 100;
```

---

### 4. ✅ 窗口布局优化

**实现方式**：
- 默认布局比例调整为：15% : 25% : 60%（侧边栏:列表:内容）
- 布局设置持久化保存
- 拖拽分割线自动保存新比例
- 响应式布局，适配不同窗口大小

**改进点**：
```
优化前：
┌─────────────────────────────────────────┐
│ [订阅列表 25%] [列表 25%] [内容 50%]      │
└─────────────────────────────────────────┘

优化后：
┌─────────────────────────────────────────┐
│ [订阅 15%] [列表 25%] [内容 60%]          │
└─────────────────────────────────────────┘
```

## 三、数据结构

### 新增数据存储

| 存储名称 | 用途 | 结构 |
|----------|------|------|
| `rss_read_status` | 已读状态 | `ReadStatus` |
| `rss_cached_articles` | 历史文章缓存 | `CachedArticles` |
| `rss_settings` | 用户设置 | `Settings` |

### 设置结构

```typescript
interface Settings {
    articlesPerPage: number;       // 每页文章数（默认20）
    autoMarkRead: boolean;         // 自动标记已读（默认true）
    cacheDays: number;              // 缓存天数（默认7）
    layout: {
        sidebarWidth: number;       // 侧边栏宽度比例
        listHeightRatio: number;    // 列表高度比例
    };
}
```
