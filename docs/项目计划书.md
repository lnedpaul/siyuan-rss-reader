## 一、项目概述

### 1.1 项目背景

思源笔记是一款深受用户喜爱的本地知识管理工具。用户希望在其中直接阅读RSS订阅源，一键将感兴趣的文章保存为笔记，实现"阅读-收藏-知识沉淀"的完整闭环。

### 1.2 现有基础

| 模块 | 完成度 | 说明 |
|------|--------|------|
| 项目结构 | ✅ 90% | Webpack + TypeScript + SCSS |
| 订阅管理 | ✅ 80% | 添加/删除订阅，预置RSS列表 |
| 文章获取 | ⚠️ 60% | 支持RSS 2.0/Atom/RSS 1.0，有解析逻辑 |
| 文章展示 | ⚠️ 40% | 纯文本展示，样式丢失严重 |
| 保存笔记 | ⚠️ 70% | 可保存，有图片本地化 |
| 定时更新 | ⚠️ 50% | 有更新检查，无状态管理 |
| 窗口布局 | ⚠️ 60% | 有拖拽调整，比例不合理 |

### 3.2 数据结构设计

```typescript
// 订阅源
interface Subscription {
  id: string;              // 唯一标识
  url: string;             // RSS链接
  name: string;            // 显示名称
  category?: string;       // 分类标签
  icon?: string;           // 图标URL
  lastFetchTime?: number;  // 最后抓取时间
  articleCount?: number;   // 文章总数
}

// 文章
interface Article {
  id: string;              // 唯一标识
  subscriptionId: string;   // 所属订阅源ID
  title: string;           // 标题
  link: string;           // 原文链接
  pubDate: string;         // 发布时间
  content: string;        // 完整内容（HTML）
  description: string;     // 摘要
  imageUrl?: string;       // 封面图
  isRead: boolean;         // 是否已读
  isSaved: boolean;        // 是否已保存
  savedPath?: string;      // 保存路径
  cachedAt: number;        // 缓存时间
}

// 用户设置
interface Settings {
  articlesPerPage: number;       // 每页文章数（默认20）
  layout: {
    sidebarWidth: number;         // 侧边栏宽度
    listHeight: number;           // 列表高度
  };
  updateInterval: number;         // 更新间隔（分钟）
  autoMarkRead: boolean;         // 自动标记已读
  defaultSavePath: string;        // 默认保存路径
  theme: 'light' | 'dark' | 'auto';  // 主题
}
```

### 4.4 样式保留方案

```typescript
// 当前：extractContent() 移除所有HTML
// 优化：白名单机制保留安全标签

const ALLOWED_TAGS = ['p', 'br', 'h1', 'h2', 'h3', 'h4', 'h5', 'h6', 
                      'strong', 'b', 'em', 'i', 'u', 'a', 'img',
                      'ul', 'ol', 'li', 'blockquote', 'pre', 'code',
                      'table', 'thead', 'tbody', 'tr', 'th', 'td'];

const DANGEROUS_ATTRS = ['onerror', 'onclick', 'onload', 'javascript:'];

function sanitizeHTML(html: string): string {
  // 1. 移除危险标签
  let clean = html.replace(/<script[^>]*>[\s\S]*?<\/script>/gi, '');
  clean = clean.replace(/<style[^>]*>[\s\S]*?<\/style>/gi, '');
  
  // 2. 移除危险属性
  DANGEROUS_ATTRS.forEach(attr => {
    clean = clean.replace(new RegExp(`${attr}=["'][^"']*["']`, 'gi'), '');
  });
  
  // 3. 处理图片
  clean = clean.replace(/<img/g, '<img style="max-width:100%;height:auto;"');
  
  return clean;
}
```

### 6.2 技术限制说明

```
⚠️ RSS协议本身限制：
   - 大多数RSS源只返回最新10-20篇文章
   - 无法强制获取更早的历史文章
   - 解决方案：本地缓存 + 分页查看已缓存文章

⚠️ 思源笔记限制：
   - 不支持直接渲染HTML
   - 保存时需转换为Markdown
   - 图片需先上传到assets目录
```
